# petfunny-media

Media for 毛孩日常 Paw Daily (IG @petfunny.tw / Facebook page), scheduled via Metricool (brand id 7357067).

- `weekN/` — images (1080x1350 JPG cards) and Reels (1080x1920 MP4) for each week. Public raw URLs are fed to Metricool.
- `tools/` — Pillow + ffmpeg scripts used to draw the cards and animated reels (Noto Sans CJK TC fonts).
- `brand/` — avatar.
- `log.md` — what was posted each week.

Style: funny/light pet content (cats & dogs), cream background #FFF6E8, orange header #FF9F43, dark brown text #4A3428, flat cartoon cat/dog mascots, footer "@petfunny.tw ｜ 毛孩日常 Paw Daily".
